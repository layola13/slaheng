# 衡 · Heng —— 高考统一引擎

## 组成

- `found/` —— 精确数与量纲：bigint / rational 精确运算、量纲与单位层，全程零浮点。
- `species/` —— 物种层：化学式与 SMILES 子集解析、规范化（canon1）、species_id；公式规范形统一为严格 Hill 序。
- `check/` —— C1 检验层：方程式配平检查、有理数配平求解、化合价、相对分子质量、反应类型判定。
- `kb/` —— 知识底座：初高中物种与方程式、原子量表（来源标签纪律）；校验器 `validate_kb` 为 SLA 实现（自建 JSON 解析器、零 Python）。
- `grade/` —— 判分运行时：题目 = 模型 + 断言 + 评分要点；三断言判定（balanced / value_eq 精确有理数 / species_id_eq）+ CLI + 样例题包。
- `lang/` —— L0/L1 语言面：`.heng` 语法冻结本、SLA 解析器、教学诊断、示例集。
- `e2e/` —— 端到端一题：`.heng` → 解析 → grade(C1) → 判分报告（对答 all_pass、错答精确报守恒差），`sh run_e2e.sh` 可复跑。
