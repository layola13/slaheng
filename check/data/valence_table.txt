# 化合价表（初中口径：元素常见化合价候选集）
# provenance: 初中化学化合价口诀与常见化合价表（人教版九年级化学口径），
#   标签 measured:textbook-cn-junior
# 用法：C1 化合价检查 = 为每个元素从其候选集选一个价态，使
#   Σ(原子数 × 价态) == 物种电荷（中性物种即 0）。无指派即响亮报错。
# 口径边界（v0.1）：同一元素在同一物种中只取一个价态——混合价态化合物
#   （如 Fe3O4）不在本表模型内；有机物不适用化合价规则，均响亮失败并注明。
#   氢只取 +1（初中口诀「钾钠氢银正一价」）：金属氢化物（如 NaH，氢 -1）
#   非初中内容，不收 -1，否则 H 的负价自由度会让有机式凑出伪分配。
# 常见原子团（根）价态（供人工核对与后续根级检查，标签同上）：
#   OH -1 | NO3 -1 | HCO3 -1 | ClO3 -1 | MnO4 -1 | NH4 +1
#   CO3 -2 | SO4 -2 | SO3 -2 | PO4 -3
